# Code of conduct

House rules for issues, pull requests and discussions in this repository.

- Be direct and respectful. Say what is wrong with the work, not with the
  person. Terse is fine; contempt is not.
- No harassment, no personal attacks, no slurs, and no publishing anyone's
  private information — addresses, employers, accounts they did not link
  here themselves.
- Disagreements are argued with evidence, the way the ledger does it: state
  the claim so it can lose, name what would prove it wrong, and let the
  outcome settle it. Being right later is a ledger entry, not a victory lap
  in the thread.
- Assume the other person read the file before assuming they did not.
- Credit goes where it belongs: to the people whose work is being built on,
  and to the person who found the problem.

Reports go through the channel in `SECURITY.md` — private reporting when it
is enabled, otherwise an issue that names the file and omits details — or a
plain issue for anything that needs no privacy. The maintainer reads them.

The maintainer may edit or remove content, close threads, and block accounts
that break these rules, and will say why in the thread unless saying so
would itself be the harm.

This applies wherever the repository is represented: issues, pull requests,
discussions, and anything posted as its maintainer.
